# Sources of the golden test data

Everything under `golden/` is either generated by the scripts in this directory, copied from
a source with a public-domain or permissive license, or a small configuration file copied
from the Hugging Face Hub. Nothing else is included.

## Images (`golden/images/`)

### Generated (synthetic)

These are drawn procedurally with numpy and Pillow from fixed random seeds (gradients,
sinusoids, noise, random ellipses and lines, and the text "hf-processors-rs" in Pillow's
built-in default font). They contain no third-party content and are covered by this
repository's license (`MIT OR Apache-2.0`).

## Audio

No audio files are stored. The Whisper test clips (`fixtures/whisper.npz`, `pcm__*` arrays)
are synthesized by `make_golden.py` (`make_clip`: sine plus chirp plus deterministic LCG
noise).

## Fixtures and manifests

`fixtures/*.npz`, `manifest.json` and `manifest_extra.json` are outputs of
`make_golden.py` and `make_golden_extra.py`. They are computed from the images, clips and
configs listed here by Hugging Face `transformers` (versions recorded in the manifests).

## Processor configs (`golden/configs/`)

Each file is the `preprocessor_config.json` of the named Hugging Face Hub repository, copied
verbatim. The file name is `<org>_<repo>.json`. These are small sets of preprocessing
parameters (sizes, means, standard deviations, flags), used here only as test inputs. No
model weights are included. The license shown is the one declared on the Hub repository
when it was checked (2026-10).
